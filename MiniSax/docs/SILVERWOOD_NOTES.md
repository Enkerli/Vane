# Silverwood Tenor Sax Context Notes

The uploaded archive contains a Reaktor ensemble named `Silverwood Tenor Sax.ens`. This handoff package does not attempt to reverse engineer the ensemble. It only uses high-level design inspiration discussed during planning.

Potentially useful conceptual controls observed/discussed:

- breath-controlled playing
- reed stiffness
- reed/mouthpiece distance or aperture
- bore damping
- mouth/bore gain interaction
- reflection-frequency-style control
- bell filtering
- breath noise
- vibrato-to-pitch
- vibrato-to-air
- flutter/growl
- rise/fall smoothing for breath response

MiniSax should not copy the Reaktor ensemble. Use these as vocabulary for parameter design and articulation testing.
