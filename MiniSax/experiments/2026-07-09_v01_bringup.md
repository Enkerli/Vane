# Experiment 2026-07-09 — v0.1 bring-up

## Goal

First working end-to-end pipeline: preset JSON → `minisax-render` →
WAVs → `analyze_renders.py` → descriptor JSON/CSV, per the handoff package.

## Starting point

No engine. STK Clarinet-style reed table + single fractional-delay bore as
the v0.1 model (handoff docs, ARCHITECTURE.md).

## Changes tried

1. Naive `delay = sr/f` pitch mapping → analyzer pitch descriptor read an
   octave low (C4 test at 131 Hz). Switched to half-period delay
   (`0.5·sr/f`, quarter-wave resonator, as STK Clarinet does).
2. First reed mapping (offset 0.6, slope −0.6) spoke only between breath
   0.45–0.65 and choked when overblown. Breath-sweep probe + small-signal
   analysis: speaking threshold ≈ `(1/R − offset)/(2|slope|)`, choke ≈
   `(1 − offset)/|slope|`; the ratio is ~1.7 no matter the slope, so no
   linear breath→pressure map can span a musical range.
3. Final v0.1: reflection base 0.97 (damping subtracts up to 0.10), reed
   offset default 0.60, slope default −0.30, compressive pressure map
   `1.30 · breath^0.38`. Speaks at breath ≈ 0.22, monotonic up to 1.0,
   no choke.

## Results

All 6 starter suite tests render non-silent, unclipped, correct octave
(C4 → 264 Hz, ~+15 cents). Soft onset test now speaks breathy
(centroid 3.3 kHz vs ~1.4 kHz for full tones). Octave leap returns cleanly
to C4. Spectrum is odd-harmonic (clarinet-like), expected for this bore.

Traceability check: `dark_002` (bellBrightness 0.62 → 0.15, derived from
`breathy_001`) lowers spectral centroid ~30% on every test; parameter
hashes distinguish the runs in `summary.csv`.

## Interesting presets saved

- `breathy_001` (handoff baseline, unchanged)
- `dark_002` (traceability variant)

## Problems

- Pitch ~15–25 cents sharp (loop filter group delay); needs the planned
  pitch correction table.
- Onset is a hard bifurcation: amplitude jumps quickly just above the
  speaking threshold. Sub-threshold breath noise exists but the transition
  could be more gradual.
- Pitch-stability descriptor is noisy on modulated tests (growl); the
  voicing gate in the tracker could be smarter.
